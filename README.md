# RAG PDF Assistant

## 🔗 Live Demo
**👉 [javid-rag-assistant.streamlit.app](https://javid-rag-assistant.streamlit.app)**

## 📌 توضیح
یک سیستم RAG (Retrieval-Augmented Generation) که از یک سند متنی پاسخ می‌دهد، منبع را نشان می‌دهد، و در صورت نبود جواب می‌گوید «در متن نیست».

## 🎯 نتیجه
- **دقت روی سوالات در متن:** ۱۰۰٪
- **دقت روی سوالات خارج از متن:** ۱۰۰٪
- **تعداد توهم:** ۰
- **مدل:** Llama 3.1 8B (Cloudflare Workers AI)
- **Embedding:** Sentence Transformers (چندزبانه)

## 🛠️ تکنولوژی
- Streamlit (رابط کاربری)
- Sentence Transformers (Embedding)
- FAISS (پایگاه برداری)
- Cloudflare Workers AI (تولید جواب)
- Python

## 🧠 نحوه‌ی کار
۱. سند به قطعه تقسیم می‌شود.
۲. هر قطعه به بردار تبدیل می‌شود.
۳. بردارها در FAISS ذخیره می‌شوند.
۴. سوال کاربر جستجو می‌شود.
۵. نزدیک‌ترین قطعه‌ها به مدل زبانی داده می‌شود.
۶. مدل فقط بر اساس متن جواب می‌دهد + منبع.

## 📊 نتایج تست
| سوال | نتیجه |
|-------|--------|
| Transformer چیست؟ | ✅ جواب درست + منبع |
| پایتخت فرانسه کجاست؟ | ✅ «در متن نیست» (۰ توهم) |

## 📝 درس‌های گرفته‌شده
- استفاده از API به جای مدل محلی، مشکل محدودیت RAM را حل کرد.
- Streamlit Secrets برای امنیت کلیدها ضروری است.
- مدل‌های Cloudflare گاهی منقضی می‌شوند و باید به‌روز شوند.
